# UM-book
Ingeneria de Software - Grupo 4

### Intrucciones para desarrollo: 
- Hacer un entorno virtual llamado venv en backend
- Instalar una version anterior de jwt en el back, en backend/app para que no de error de string
- En el front en frontend/um-book-app instalar con comandos:
   npm install bootstrap (para que funcione bootstrap)
   npm install jwt-decode (para decodificar el token) y saber quien es el usuario logeado
   npm install @angular/forms (para tener los formularios bien)
